# wsc ブラウザ拡張機能

Chrome / Microsoft Edge 対応の拡張機能です。  
現在閲覧中のページを **ページ再読み込みなし** で PC・モバイル両方のフルページスクリーンショットとして保存します。

> **POSTリクエストで表示されたページ（フォーム送信後の確認画面など）も正確にキャプチャできます。**

## しくみ

拡張機能は Chrome DevTools Protocol の `chrome.debugger` API を使い、現在のタブを直接操作してキャプチャします。  
Playwright による URL ナビゲーションは **行いません**。

1. **PC**: 現在の表示状態のままフルページをキャプチャ
2. **モバイル**: デバイスエミュレーション（iPhone 13 相当 390×844）を適用 → キャプチャ → 元の状態に復元
3. キャプチャした画像（base64 PNG）を `wsc serve` が提供するローカルサーバー（`http://127.0.0.1:4242`）に送信し、通常の wsc データとして保存

## 必要な準備

`wsc serve` をローカルで起動しておく必要があります。

```bash
# プロジェクトディレクトリで実行
wsc serve

# ストレージディレクトリを指定する場合
wsc serve --storage-dir /path/to/wsc-data
```

拡張機能のポップアップ右上に「サーバー稼働中」と表示されれば準備完了です。

## インストール手順

### Chrome

1. Chrome のアドレスバーに `chrome://extensions` を入力
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `extension/` フォルダを選択

### Microsoft Edge

1. Edge のアドレスバーに `edge://extensions` を入力
2. 左下の「開発者モード」をオンにする
3. 「展開して読み込む」をクリック
4. この `extension/` フォルダを選択

## 使い方

1. キャプチャしたいページを開く
2. ツールバーの 📸 **wsc** アイコンをクリック
3. 必要に応じてラベルを入力
4. 「**PC・モバイル 両方キャプチャ**」ボタンをクリック
5. 完了後、`wsc list` でキャプチャの一覧を確認できる

## 注意事項

- `chrome.debugger` API を使用するため、インストール時に「デバッガーを使用してタブを操作する」の確認が表示されます
- デバッガー接続中はアドレスバーに警告バナーが表示されます（キャプチャ完了後に自動で消えます）
- `http://` ページには通常通り使えます。`chrome://` や `edge://` などの内部ページは対象外です

## サーバー API（参考）

| メソッド | エンドポイント | 説明 |
|---------|--------------|------|
| GET | `/status` | サーバーの稼働確認 |
| GET | `/captures` | 直近20件のキャプチャ一覧 |
| POST | `/capture` | Playwright による URL キャプチャ（CLI向け） |
| POST | `/capture-image` | 事前キャプチャ済み画像の保存（拡張機能向け） |
